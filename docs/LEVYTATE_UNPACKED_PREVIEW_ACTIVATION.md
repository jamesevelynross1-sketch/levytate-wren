# Unpacked — live AI Preview activation (22 October 2026)

## Purpose

The user opens an approved apprenticeship, then **Unpacked** automatically
transforms official occupational summaries, duties and knowledge/skills/
behaviours into a clear, engaging, structured explanation. The text is
generated by AI (not a static fake) and the original Skills England record
is always linked.

## Provider

Preview uses **Vercel AI Gateway** with
`openai/gpt-5.4-mini` via its OpenAI-compatible
`POST /v1/chat/completions` endpoint. Vercel offers a monthly AI Gateway
free-credit allowance for free-tier teams; confirm the actual available
balance and disable automatic top-up. Do not assume a ChatGPT subscription
includes developer API credits.

Model authentication is through the short-lived
`x-vercel-oidc-token` request header supplied by Vercel's OIDC Federation,
or an intentionally configured server-side `AI_GATEWAY_API_KEY`.
The token is never returned, logged, placed in code, stored in a cache key
or exposed to the browser. Vercel OIDC may need to be enabled at
Project → Settings → Security → Secure backend access with OIDC federation.

If using a manually issued gateway key, add only as a Sensitive Vercel
Preview variable scoped to `feature/levytate-explore-public-pwa`.
Never paste any key into a chat or GitHub repository.

## Preview activation switches

Both must be present on the protected Preview branch:

- `LEVYTATE_EXPLORE_AI_ENABLED=true`
- `LEVYTATE_EXPLORE_AI_RUNTIME=gateway-preview`

The runtime additionally checks `VERCEL_ENV=preview` and the exact
`VERCEL_GIT_COMMIT_REF=feature/levytate-explore-public-pwa`. It will NOT
activate on a production domain, another Preview branch or an isolated
Preview lacking Gateway authentication.

## Processing and cost

1. Browser selects an individual standard. Existing Explore React UI
   immediately calls the same `POST /api/levytate-explore/de-fluff`
   route; public feature label remains **Unpacked**.
2. Server checks branch and feature gates, parses ST code and checks the
   approved catalogue.
3. Server fetches fresh Skills England occupational evidence using the
   already configured server-only Skills England key. An **exact linked ST
   productCode** is required, and explicitly retired official products
   are rejected.
4. Gateway receives ONLY official public evidence, source metadata and
   plain-language writing instructions—no employee, company or manager data.
5. The model returns strict JSON matching the Unpacked structured schema.
   Zod validates field types, lengths and list cardinalities before display.
   No guessed course guarantees, salary or funding claims.
6. Next.js `unstable_cache` keys the narrative to official source content,
   standard/version, model and prompt revision for seven days. Repeat visits
   reuse the generated text without an unnecessary second model call.
7. Preview instance budget permits no more than 12 new generation attempts
   per serverless instance per UTC day; this is **not a global budget** and
   cannot protect a fully public rollout.

**Do not treat this Preview mode as public-production ready.** The
longer-term global atomic cache/lease, billing controls, distributed
network quotas and correct isolated Supabase environment must be completed
and verified before public enablement. The database proposal is in
`docs/database/LEVYTATE_EXPLORE_AI_NARRATIVE_CACHE_PROPOSAL.sql`.
No migration is applied by this branch.

The user's previously agreed public-website and app distribution remains
free to access; live AI tokens are a separate provider cost and must stay
within the free credit while testing.

## Release and acceptance

- Confirm OIDC or Gateway key availability using a masked Preview-only
  diagnostic; never reveal credentials.
- Confirm source matches for ST0078, ST0584, ST0118 and ST1512.
- Generate one genuine response and ensure source-grounded content,
  structured fields and no unsuitable claims.
- Repeat the same request and confirm the cache returns the result without
  a second model bill.
- Test disabled feature, invalid ST, missing source, exhausted free credit,
  provider timeout, retired standard, and invalid JSON.
- Keep employee enquiry submissions separately disabled.
- Perform a supervised review of content quality before a public launch.
