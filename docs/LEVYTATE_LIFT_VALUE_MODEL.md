# LevyTate Lift — value and proof model

Lift keeps four categories separate: capacity, financial return, quality/service, and continuity/resilience.

The optional capacity model is:

`hours = affected_people × minutes_released_per_person_per_week ÷ 60 × applicable_weeks × realised_fraction`

All inputs are employer-supplied assumptions with units and a period. Missing values stay unknown. Lift never derives time saved, adoption, salary rates or financial returns from assessment answers.

An optional capacity-equivalent value is `hours × employer_supplied_loaded_hourly_rate`. It is explicitly not a cash saving. Cash ROI is not shown unless compatible monetised benefits, costs and periods have a defensible basis. Training, employee time, management support, tools and implementation costs stay separate. Funding stays separate.

Shared-benefit identifiers expose overlapping claims. Alternative scenarios, overlapping opportunities and capacity value plus cash value from the same hours are not summed.

Proof states are `signal_identified`, `work_context_confirmed`, `change_tested`, `outcome_evidenced`, `paused`, `not_supported` and `no_improvement`. A trial requires a recorded decision, owner, agreed scope, intended measure and baseline. An evidenced outcome additionally requires comparable outcome evidence and authorised review. Negative and no-improvement results remain durable records.
