# LevyTate Lift — DPIA addendum (draft for review)

Status: draft. This document does not approve live use.

Lift processes employee assessment responses, limited work context, independent manager observations, employer decisions and operational outcome evidence. Its purpose is to identify evidence-backed development and work-improvement opportunities, not to make automated employment decisions or infer wellbeing.

Key controls include data minimisation, purpose-bound versioned instruments, explicit source and permission metadata, private drafts, independent release rules, current-manager checks, tenant scoping, server-owned interpretation, immutable evidence/decision history, minimum-five aggregation and complementary suppression. Pastoral support data is explicitly excluded.

Before live use, the controller must complete lawful-basis, transparency, retention, subject-rights, contestability, equality/accessibility, human-review, international-transfer, model-provider and incident-response assessments. The pilot instrument also needs expert measurement review. Live activation must not occur merely because software tests pass.
